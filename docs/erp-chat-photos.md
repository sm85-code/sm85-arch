# Foto chat pembeli

Toolbar chat menyediakan Galeri, Kamera (capture environment pada browser HP yang mendukung), serta dialog Produk/Pesanan dengan kartu dari toko percakapan. Pilihan foto diunggah dahulu, kemudian ditampilkan sebagai pratinjau. Hanya tombol Kirim yang mengirim pesan; teks dan foto dikirim terpisah. Batas lokal/server 10 MB JPG/JPEG/PNG; format lain (termasuk HEIC) harus dikonversi terlebih dahulu.

Backend menggunakan v2.sellerchat.upload_image (multipart file, shop signature), kemudian v2.sellerchat.send_message dengan message_type=image dan content.image_url. Sumber kontrak: Shopee FAQ 137 daftar All Chat APIs, dokumentasi send_message 672/upload_image 683; cross-check pyshopee2/chat.py dan wjpxxx/shopeego sellerchat/entity. Detail endpoint chat belum ada di repo api-docs saat perubahan ini; halaman detail resmi tidak dapat diakses dari lingkungan kerja. Jangan mengganti upload chat dengan upload foto katalog hanya karena keduanya mengunggah gambar. Izin akun live tetap perlu Shopee; penolakan provider ditampilkan, tidak disamarkan sebagai sukses.

mpe_chat_photos menyimpan ID, toko, URL hasil provider, waktu upload; tidak menyimpan bytes/file di ERP. Startup create_all menambahkan tabel. Send menerima ID foto server, tidak menerima URL bebas, dan memastikan toko cocok serta umur upload kurang dari 24 jam. Toko/staf tetap diperiksa melalui account(..., chat). Receipt pengiriman existing tetap dipakai: dedup operation ID, tidak mengulang hasil belum pasti. Menghapus lampiran di UI membatalkan draft; tidak menghapus media pada penyimpanan Shopee (API penghapusan tidak tersedia).

Validasi memakai provider mock, tanpa upload/pesan produksi: multipart signature path, jenis/ukuran, URL aman, upload tidak mengirim, scoped send, dedup dan gambar toko lain ditolak. Browser 390/1440 memeriksa dialog, preview, explicit send, selector kamera, invalid format, no overflow/errors. Kamera fisik/permission dan akun Shopee live belum diverifikasi.
